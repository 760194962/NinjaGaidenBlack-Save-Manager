# 忍者外传 黑之章：日版与美版差异

对象：两份从 XISO 解出的目录 `Ninja Gaiden Black (Japan) (En,Ja)` 与 `Ninja Gaiden Black (USA) (En,Ja)`。

## 结论

**游戏内容（资源文件）完全相同，只有 5 个 XBE 可执行文件不同，差异是区域标记等头部/证书字段。**
两个版本都是英日双语（En,Ja），不是"日版只有日语、美版只有英语"。

## 1. 文件层面

| 项目 | 结果 |
|---|---|
| 文件数量 | 两边都是 249 个 |
| 文件名 / 大小 | 逐一相同 |
| `Media\` 目录 | 文件列表相同 |
| 内容不同的文件 | 仅 5 个：`default.xbe`、`NinjaTomoe.xbe`、`NinjaTrilogy.xbe`、`update.xbe`、`dashupdate.xbe` |
| 其余文件（所有 `.afs`、`Media\*` 等） | 逐字节相同（`cmp`） |

5 个 XBE 的文件大小两边一致，不同字节数各约 512 个（`default.xbe` 514，`NinjaTomoe.xbe` 513，`NinjaTrilogy.xbe` 512，`update.xbe` 513，`dashupdate.xbe` 513），说明差异集中在 XBE 头 / 证书（Certificate）里，不是代码或资源重编。

## 2. `default.xbe` 证书字段对比

| 字段 | 日版 | 美版 |
|---|---|---|
| 标题 | NINJA GAIDEN Black | NINJA GAIDEN Black |
| Title ID | `5443000D` | `5443000D` |
| 允许区域（Game Region） | `0x2`（日本） | `0x1`（北美） |
| 分级字段（Game Ratings） | `0x0` | `0x2` |
| 证书版本号 | 4 | 5 |
| XBE 构建时间戳 | 2005-09-01 19:52:40 UTC | 2005-09-01 19:52:52 UTC（相差 12 秒） |

- 区域标志位含义：`0x1` 北美 NTSC-U、`0x2` 日本 NTSC-J、`0x4` 其他地区 PAL。
- 分级字段两边不同（0 vs 2），具体含义未验证，推测与美版的分级信息有关。
- 除上述字段外，约 500 字节的差异里应还包含 XBE 头的数字签名（未逐字节核对）。

## 3. 对使用的影响

- **真机**：区域锁。日版标 NTSC-J、美版标 NTSC-U，区域不匹配的主机可能拒绝运行。
- **模拟器（xemu 等）**：一般不检查区域，两个版本都能用。
- **存档**：Title ID 相同，都是 `5443000D`，存档目录名 `UDATA\5443000d\` 一致。本工具对两个版本不做区分。

## 4. 局限（没有验证的部分）

- 只比对了文件的二进制内容，没有实际运行两个版本。游戏里文字、血液表现、难度或隐藏要素等方面有无差别，没有测试；从文件看，这些差别没有体现在资源文件里。
- `.afs` 内部是否有差异无需另测：整个文件逐字节相同。
- 5 个 XBE 中除证书字段以外的差异位置，没有逐处标注。
- 比对时间：2026-10-06。
